# ai_cache
The Instagram account that posts daily.

Pictures for [@ai_cache](https://www.instagram.com/ai_cache/)'s Instagram posts, one folder per post
(`01.jpg`, `02.jpg`, ... in slide order). Instagram's API only takes pictures by public link, so it
fetches them from here: this repository has to stay **public**.

They're made by the slide maker in `instagram/` of the owner's my-desktop-agent repository.
